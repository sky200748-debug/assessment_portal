🎓 Intelligent Online Assessment Portal

A web-based assessment management system built using Python, Django, SQLite3, HTML, CSS, Bootstrap and JavaScript.

The platform simplifies online examinations by providing separate access and functionalities for Admin, Staff and Students.

🚀 Features

👨‍💼 Admin Module

- Manage users and accounts
- Manage staff and student access
- Monitor examination activities
- View assessment statistics

👩‍🏫 Staff Module

- Create and manage examinations
- Add and manage questions
- Organize assessments
- Monitor student examination activities

👨‍🎓 Student Module

- Secure student login
- View available examinations
- Attend online assessments
- Submit examination responses
- View assessment results

📊 Additional Features

- Role-Based Access Control (RBAC)
- Dashboard with visual statistics
- Chart.js data visualization
- Database management using SQLite3
- Responsive user interface using Bootstrap

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/sky200748-debug/assessment_portal.git

2. Navigate to the project

cd assessment_portal

3. Create a virtual environment

python -m venv venv

4. Activate the environment (Windows)

venv\Scripts\activate

5. Install Django

pip install django

Install any additional dependencies required by the project.

6. Apply database migrations

python manage.py migrate

7. Start the development server

python manage.py runserver

8. Open in your browser

http://127.0.0.1:8000/
